# 멜양번역기 내려받기

화면의 글자를 마우스로 드래그하면 한국어로 번역해 주는 Windows 프로그램입니다. 영어·일본어·중국어를 번역합니다.

## 받기

1. **[최신 버전 받기](https://github.com/ImaHost/melyangtranslate-releases/releases/latest)** 를 눌러 `MelyangTranslator-<버전>-portable.exe` 를 받습니다.
2. 원하는 폴더에 두고 실행합니다. 설치는 필요 없습니다.
3. 처음 실행하면 **"Windows의 PC 보호"** 창이 뜰 수 있습니다. **추가 정보 → 실행** 을 누르세요. (코드 서명을 하지 않은 프로그램이라 뜹니다)

## 쓰는 법

- `Ctrl+Alt+T` 를 누르고 번역할 부분을 드래그하면 바로 옆에 번역이 뜹니다.
- 일본어·중국어를 번역하려면 메인 창의 **일본어·중국어 글자 인식 설치** 를 한 번 누르세요(관리자 승인 창이 뜹니다).
- 창을 닫아도 작업 표시줄 오른쪽 트레이의 강아지 아이콘으로 계속 실행됩니다.

## 업데이트

새 버전이 나오면 프로그램 메인 창에 알림과 **업데이트** 버튼이 뜹니다. 누르면 새 버전으로 바뀌어 다시 실행됩니다.

---

이 저장소에는 실행 파일만 올라갑니다. 번역은 Google 번역을 쓰며, 인식한 글자가 번역을 위해 Google로 전송됩니다.
